# Learner Management System

A production-style backend system for managing courses, students, and enrollments — built with Java 17 and Spring Boot.

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Gradle
- Docker (planned)
- GitHub Actions CI/CD (planned)

## Features (In Progress)
- [ ] Student registration and management
- [ ] Course creation and management
- [ ] Enrollment service with transaction management
- [ ] REST APIs with proper error handling
- [ ] Authentication with JWT (planned)

## Getting Started

### Prerequisites
- Java 17
- MySQL
- Gradle

### Run Locally
```bash
git clone https://github.com/ramchoudhary-cloud/E-Learning-live.git
cd E-Learning-live
./gradlew bootRun
```
